# 当前业务规则（实施唯一口径）

> 更新：2026-08-21  
> 本文件是当前实现的业务口径。其他“修改建议/评审/重构方案”文档仅用于历史追溯；如有冲突，以本文件和 `页面类型情况说明.txt` 为准。

## 技术方案

- 使用 DrissionPage。
- 一个 `ChromiumPage` 浏览器实例。
- 预创建 N 个独立 tab，N=`workers`。
- 每个线程在一个任务期间独占一个 tab，完成后归还 tab 池。
- 不使用多浏览器实例并发。
- 使用固定美国 VPN；程序不自动切换 IP，也不自动继承系统代理。只有显式配置 proxy 时才使用代理。
- 正式结果只来自实时 Amazon 页面。本地 HTML 仅用于解析规则单元测试，不作为业务数据源。

## 页面状态

| 页面情况 | 内部状态 | 六列结果 |
|---|---|---|
| 明确 Page Not Found | `page_not_found` | 折扣类型和一致性为 `-` |
| 页面存在但没有显示主价格 | `sold_out` | 折扣类型和一致性为 `-` |
| 页面正常且有主价格 | `ok` | 按四种类型计算 |
| Captcha、加载失败、浏览器异常 | `crawl_error` | 不得归类售罄 |
| 页面结构无法可靠解析 | `parse_error` | 不得归类售罄 |

## 四种折扣类型

页面同时出现多种证据时，固定优先级：

```text
coupon > code > 价格折扣 > 原价调整
```

周报的“本周折扣形式”只用于记录预期是否匹配，不覆盖页面真实分类。

### 原价调整

页面没有 Coupon、Code、价格折扣证据。

```text
展示价格 = 页面主价格
折扣值 = 目标成交价 - 正常售价
最终价格 = 展示价格
```

### Code

页面出现 `Save X% at checkout` 等明确文案。

```text
展示价格 = 页面主价格
折扣值 = X%
最终价格 = 展示价格 × (1-X%)
```

### 价格折扣

页面主价格区域出现 `-X%`/Save X%，且展示价格已经是折后价。

```text
展示价格 = 页面折后主价格
折扣值 = X%
最终价格 = 展示价格
```

不得根据 Save% 再次扣减展示价格。

### Coupon

```text
折扣值：优先显示 Coupon 百分比；没有百分比时显示优惠金额
最终价格：优先使用页面明确的 Coupon 后最终价
        其次使用 展示价格-Saving金额
        最后使用 展示价格×(1-Coupon百分比)
```

`Saving $15.00`是优惠金额，不是最终价格。

## 固定六列

```text
展示价格
折扣类型
折扣值
最终价格
一致性检查
时间戳
```

所有目标子表统一为紧凑的 A:M，不保留中间空白列：

```text
A:G  ASIN / SKU / 尺寸 / 正常售价 / 本周折扣形式 / 本周折扣% / 目标成交价
H:M  展示价格 / 折扣类型 / 折扣值 / 最终价格 / 一致性检查 / 时间戳
```

- 表头固定在第 2 行，数据从第 3 行开始。
- 每日运行先从原始表读取并刷新 A:G，再实时抓取，最后写 H:M。
- 清理旧追加列前先备份；只清理由完整六列表头确认出的旧结果区，不碰其他业务列。
- 不再按每个子表动态决定输出位置，也不依赖旧迁移记录。

## 飞书每日推送流程

```text
读取原始周报 → 保存源数据快照 → 备份目标子表
→ 刷新目标 A:G 并清空本次 H:M → Amazon 实时抓取
→ 计算六列 → 风险检查 → 写入 H:M → 保存日志/CSV/每日摘要
```

目标表刷新和抓取必须使用同一次源数据读取结果，避免原始数据与校验结果错位。

## 一致性

```text
差值 = 最终价格 - 目标成交价
abs(差值) <= price_tolerance → ✅
否则 → ❌
```

默认容差：`0.50`。输出示例：`✅(0.00)`、`✅(+0.20)`、`❌(-0.75)`、`-`。

所有金额使用 `Decimal`，按 `ROUND_HALF_UP` 保留两位小数。

## 目标成交价

- 优先读取飞书/Excel 已计算数值。
- 上传 xlsx 的公式没有缓存值时，允许使用已验证的本地 `calc_target_price()`。
- `local_fallback`只记录提示，不阻止推送。
- 本地也无法计算时标记 `missing`；只有 missing 才触发数据风险保护。

## 缓存

- 缓存保存实时页面解析后的结构化结果，不保存或复用本地 HTML 作为业务结果。
- 普通新批次默认实时抓取。
- `--resume`只恢复同一数据签名、规则版本和有效期内的中断批次。
- `--force-fetch`忽略缓存，实时重抓。
- `--asins`自动 dry-run，不写飞书。
