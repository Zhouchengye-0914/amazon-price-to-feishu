# amazon_daily 操作手册（六列版 · 2026-08-21 重构）

> 当前价格、折扣和页面分类规则以同目录 `当前业务规则.md` 为准。

> 本手册随文件夹一起拷贝，换设备后照此操作即可。
> 目标表统一为紧凑 A:M；每日先刷新 A:G，再实时抓取并写 H:M。

---

## 一、部署（新设备，约 3 分钟）

### 第 1 步：安装 Python（只需一次）

1. 打开 https://www.python.org/downloads/ 下载 **Python 3.10+**
2. 安装时**务必勾选** `Add Python to PATH`
3. 验证：命令行输入 `python --version` 能看到版本号

### 第 2 步：一键部署

1. 把整个 `amazon_daily` 文件夹拷贝到新电脑
2. 双击根目录 **启动中心.bat**，选择“首次部署”
3. 看到 `部署完成！` 即成功
4. 在启动中心选择“部署验收”，确认配置、核心模块和自动测试全部通过

### 第 3 步：配置飞书（只需一次）

打开 `config/config.json`，填入：

```json
{
  "feishu_app_secret": "你的App Secret"
}
```

（或设置环境变量 `FS_APP_SECRET`）

### 第 4 步：先跑 PD03 验证

```powershell
.venv\Scripts\python.exe run.py --sheets PD03 --force-fetch
```

程序会自动备份目标 PD03，刷新 A:G，实时抓取，再写 H:M。确认 A2:M2 表头连续且数据正确后，再跑全量。

## 二、日常使用

### 方式 A：双击运行（最常用）

双击根目录 **`启动中心.bat`**，选择“全量实时运行”。

### 方式 B：命令行

```powershell
cd amazon_daily

python run.py                         # 全流程（默认无头）
python run.py --no-headless           # 显示浏览器（调试）
python run.py --limit 5               # 每表前 5 行（自动 dry-run，不改飞书）
python run.py --sheets PD03           # 只跑 PD03
python run.py --asins B0...,B0...     # 只抓指定 ASIN（自动 dry-run，类型专项测试）
python run.py --dry-run               # 只读+计算+本地输出，不改飞书
python run.py --fetch-only            # 同步+抓取，不写六列
python run.py --push-only             # 用最近快照缓存推送
python run.py --force-fetch           # 忽略缓存重新抓取
python run.py --resume                # 恢复最近有效的未完成批次（中断后接着跑）
python run.py --force-push            # 异常比例超阈值时人工确认推送
```

> 中断后接着跑：直接 `python run.py --resume`，已完成的 ASIN 不再打开页面，只补未完成和技术失败的。

## 三、每日自动运行（计划任务）

```powershell
在启动中心选择“注册每日 08:00 / 16:00 计划任务”；取消时选择“删除计划任务”。
```

或手动：`taskschd.msc` → 创建基本任务 → 程序 `python.exe`、参数 `run.py`、起始于 `C:\...\amazon_daily`。

> 计划任务建议直接跑 `python.exe run.py`，不要跑带 `pause` 的 bat。

## 四、固定六列说明

| 列 | 含义 | 示例 |
|----|------|------|
| 展示价格 | 页面当前主价（Buy Box/Price to Pay） | `59.99` |
| 折扣类型 | 原价调整 / code / 价格折扣 / coupon（异常为 `-`） | `coupon` |
| 折扣值 | 百分比带 `%`，金额不带 `%` | `25%`、`-10.00` |
| 最终价格 | 实际成交价（两位小数） | `44.99` |
| 一致性检查 | 最终价 − 目标成交价，≤0.50 为 ✅ | `✅(+0.20)` |
| 时间戳 | 抓取完成北京时间 | `2026-08-21 16:00:00` |

- Page Not Found / 售罄 / 技术异常：六列除时间戳外为空，一致性为 `-`。
- 原价调整折扣值 = 目标成交价 − 正常售价（来自周报，不是划线价反推）。
- 价格折扣页面的展示价格**已经是折后价**，不会重复打折。
- 金额全部 Decimal 计算，两位小数 ROUND_HALF_UP。

## 五、产物与日志

| 位置 | 内容 |
|------|------|
| `outputs\logs\run_时间.log` | 运行日志（保留 30 个） |
| `outputs\snapshots\{run_id}\` | 原始周报快照 |
| `outputs\fetch_cache\{run_id}\` | 抓取缓存（断点续跑用，勿删） |
| `outputs\csv\` | 完整诊断 CSV（含状态/规则/原始文案） |
| `outputs\debug\{run_id}\` | 异常页截图+HTML+diagnostic.json（保留 7 天） |
| `outputs\daily_runs\YYYY-MM-DD\` | 每次正式运行摘要 |
| `outputs\target_backups\{run_id}\` | 每个子表写入前备份 |

出问题先看当天日志末尾的 ERROR / 告警。

## 六、常见问题排查

| 症状 | 原因 | 解决 |
|------|------|------|
| 全部显示 `-` 或售罄 | VPN 不是美国节点或页面被风控 | 固定美国 VPN，检查异常证据后重跑 |
| 报 `91403 Forbidden` | 表格没共享给应用 | 原始表共享（只读）+ 目标表共享（可编辑） |
| 报 `token 无效/认证失败` | App Secret 填错 | 检查 config/config.json 或环境变量 FS_APP_SECRET |
| 提示"K 列公式无法读取" | 原始表公式未计算 | 打开飞书表格触发一次计算后重跑 |
| 浏览器起不来（WebSocket 404） | DrissionPage 缓存损坏 | 删除 `%LOCALAPPDATA%\Temp\DrissionPage` 后重试 |
| 中断了想接着跑 | — | 直接重跑，同一快照内自动断点续跑 |
| 想强制全量重抓 | — | `python run.py --force-fetch` |

## 七、重要规则（请勿修改）

1. **必须美国节点**：本项目不做 IP 检测，运行环境需固定美国 VPN。
2. **六列固定**：正常页面只有四种类型；异常输出 `-`，不伪造 `0`。
3. **折扣只读页面**：禁止用划线价反推；Deal/Save% 不重复扣减。
4. **一致性**：|最终价格 − 目标成交价| ≤ 0.50（可配 price_tolerance）。
5. **目标成交价**：按表头自动识别（PD05 可在 L，其余可在 K）；公式无缓存值时使用已验证的本地 Decimal 计算。
6. **缓存指纹**：换周报/改规则/改容差后旧缓存自动失效。
7. **推送顺序固定**：同一次源数据快照先刷新 A:G，再写本次实时抓取的 H:M。
