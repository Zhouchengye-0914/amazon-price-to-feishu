# 纯净交付清单

版本日期：2026-08-21

## 新设备启用

1. 解压到普通本地目录，路径中不要使用网络盘。
2. 安装 Python 3.10 或更高版本，并勾选 `Add Python to PATH`。
3. 双击根目录 `启动中心.bat`，选择“首次部署”。
4. 在 `config/config.json` 填写 `feishu_app_secret`，或设置环境变量 `FS_APP_SECRET`。
5. 固定美国 VPN后，在启动中心选择“部署验收”。
6. 在启动中心先运行 PD03，确认后再执行全量任务。
7. 如需计划任务，以管理员身份打开启动中心并选择注册计划任务。

## 交付物包含

- 核心 Python 代码及 `amazon` 抓取模块。
- `config.json`（不含 App Secret）和配置模板。
- 部署、人工运行、无交互定时运行、验收脚本。
- 当前业务规则、操作手册和 README。
- 自动测试；用于跨设备部署后验收。

## 交付物不包含

- `.venv`、`.env`、Python 缓存。
- 本地周报或 HTML 样本。
- 历史方案、实验脚本。
- 抓取缓存、日志、CSV、截图和飞书备份。

程序首次运行会自动创建 `outputs` 及其子目录。每日记录位于 `outputs/daily_runs/YYYY-MM-DD`。
